# Airbnb Learning

by Victor Willemer, Nur Azreik and Trung Pham

In this project we predict the listing prices for Airbnb accommodations located in Barcelona using various models. To train our models we used the data of the 14th September 2025, which can be found on this webpage: https://insideairbnb.com/get-the-data/.

This project was created as part of a Machine Learning course at the University of Göttingen SoSe2026.
